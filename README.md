# AAZ Global Logistics & Autos

Premium static website concept for an executive chauffeur / transportation business based in Abuja.

## Current structure

- Home
- Services
- Fleet
- About
- Contact / booking request
- Responsive navigation
- Scroll reveal and route motion
- SEO metadata + LocalBusiness JSON-LD
- robots.txt + sitemap.xml
- WhatsApp-ready booking flow
- AAZ logo in `assets/logo.png`

## Before production launch

1. Replace every `YOUR-DOMAIN.example` value with the real domain.
2. Add the driver's real WhatsApp number to `script.js`:
   `whatsappNumber: "234XXXXXXXXXX"`
3. Replace representative fleet categories/images with the driver's actual vehicles and photos.
4. Add real driver photo, service-area wording and any verified hotel/corporate relationships.
5. Create/update the company's Google Business Profile and connect the site to Search Console.
6. Replace remote stock imagery with locally hosted licensed assets when the final content pack is ready.
